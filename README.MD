# Object Detection System Using Arduino, Ultrasonic Sensor, and Servo Motor

## 1. Introduction

This project is a basic object detection system built using an Arduino UNO, an ultrasonic sensor (HC-SR04), and a servo motor. It can detect objects within a certain range and scan the environment by rotating the sensor.

## 2. Components Used

- Arduino UNO  
- Ultrasonic Sensor (HC-SR04)  
- Servo Motor (SG90 or similar)  
- Jumper wires  
- Breadboard  
- Power supply (USB or battery)

## 3. Working Principle

- The ultrasonic sensor sends out sound waves and waits for them to reflect off an object.
- The time taken for the echo to return is used to calculate the distance.
- The servo motor rotates the sensor to scan the surroundings.
- If an object is detected within a set distance (e.g., 20 cm), the system can trigger an alert or take action.
